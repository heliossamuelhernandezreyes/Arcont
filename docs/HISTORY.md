# Historia de ARCONT

ARCONT comenzó como prototipo de videojuego en Godot orientado a tercera persona y dispositivos móviles. Durante su desarrollo se exploraron combate, IA, navegación, destrucción, generación procedural de bosque, pipelines 3D y optimización Android.

El 12 de septiembre de 2026 se decidió retirar el juego como producto y reconvertir el repositorio en un **banco de información para el desarrollo de otros juegos**.

## Política desde esta transición

- `main` contiene conocimiento y documentación, no un juego ejecutable.
- Los nuevos videojuegos deben tener repositorios independientes.
- ARCONT puede documentar patrones, benchmarks, experimentos, referencias y resultados negativos.
- El historial previo de Git se conserva como registro técnico, no como base de producción.

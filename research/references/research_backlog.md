# Broad Research Backlog

This deliberately includes subjects with weak immediate relevance. The goal is organized optionality, not immediate implementation.

## Rendering / graphics
PBR, lighting, GI tradeoffs, decals, volumetrics, particles, temporal effects, anti-aliasing, upscaling, texture streaming, virtual texturing concepts, impostors, meshlets/GPU-driven rendering, procedural materials, stylization, HDR, color grading.

## Simulation / physics
Ragdolls, active ragdolls, constraints, vehicles, fracture/destruction, rope/cloth, fluids as VFX, projectile simulation, penetration/ricochet, deterministic physics limits.

## AI
Utility systems, BTs, GOAP, HTN, influence maps, tactical heatmaps, squad roles, perception uncertainty, memory decay, threat assessment, dynamic difficulty, director systems, procedural encounter composition.

## Animation
Retargeting, additive layers, IK, root motion, motion warping, motion matching, inertialization, pose search, procedural recoil, physical animation, facial animation, creature locomotion.

## Audio
Convolution/reverb approximations, portals/rooms, occlusion, adaptive music, procedural ambience, dynamic mixing, loudness, voice management, haptics-audio coupling.

## UX/accessibility
Control remapping, gyro, one-handed modes, subtitles, directional captions, colorblind support, reduced motion, aim accessibility, difficulty assists, UI scaling, localization, screen-reader feasibility.

## Production
Version control for binary assets, Git LFS strategy, Blender automation, asset validation, build caching, CI matrices, crash reporting, profiling capture, release channels, store packaging, licensing/SBOM.

## Design
Combat economies, resource pressure, enemy-role composition, progression, mastery curves, onboarding, tutorials without interruption, systemic narrative, companion trust, horror/tension, replayability.

## Platform/future
Desktop/console input, cloud saves, achievements, controller haptics, online co-op architecture, rollback, dedicated servers, anti-cheat, modding, UGC, cross-play — research-only until product scope justifies them.

## Business/operations
Playtest methodology, telemetry ethics/privacy, community feedback triage, accessibility QA, localization QA, performance device matrix, minimum-spec definition, content rating implications.

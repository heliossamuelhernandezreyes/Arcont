# Pine Tree 01 — Arcont mobile derivatives

Source: Poly Haven `pine_tree_01`, CC0 1.0.
Source page: https://polyhaven.com/a/pine_tree_01
These GLB files are generated derivatives for Arcont's mobile runtime.

Intended per-tree triangle ceilings and initial distance policy:
- LOD0: <=30,000 triangles — 0 to ~3 m. Measured tree profile + alpha-cut Poly Haven twig cards + textured trunk.
- LOD1: <=15,000 triangles — ~3 to 10 m. Reduced alpha-cut foliage-card density.
- LOD2: <=6,000 triangles — ~10 to 25 m. Coarse foliage-card representation preserving crown silhouette.
- LOD3: <=2,000 triangles — ~25 to 50 m. Measured silhouette-profile geometry.
- HLOD: <=96 triangles — ~50 to 310 m. Very coarse measured far-silhouette geometry.

The close/mid LODs deliberately avoid extreme whole-tree COLLAPSE decimation because it creates stretched foliage triangles.
Distances are initial mobile tuning values and must be validated on-device.
Generated by `tools/blender/decimate_pine_tree.py`.
The original ~905 MiB source buffer is not committed to the runtime repository.
